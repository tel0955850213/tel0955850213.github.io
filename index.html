DELIBERATE PRACTICE LOOP

每次練習都照這 6 步

1. 單一目標今天只練一個能力，例如「不用筆記解釋 DNS」。
2. 先測再學先做 5–10 分鐘，確定你到底卡在哪。
3. 剛好超出能力題目要讓你失敗，但不是完全做不了。
4. 立即回饋用測試、log、正確答案、AI review 找出誤差。
5. 錯誤分類不知道概念／記不住／操作錯／判斷錯，四選一。
6. 間隔重測隔 1 天、7 天各做一次變化題，過才勾。

JOB-READY GATE

可以開始大量投遞的門檻

  • Python：能自己寫 150–300 行小工具，能 debug，不靠 AI 生成核心邏輯。
  • Linux：遇到 process / port / permission / package 問題能自己定位。
  • Networking：能從 browser → DNS → TCP/TLS → Load Balancer → server 完整說一次。
  • Docker：能把 Python API containerize 並處理 logs / env / ports。
  • AWS：能設計並部署一個有 VPC、compute、storage/database、IAM、monitoring 的系統。
  • Architecture：每個設計都能說明 reliability / security / cost / trade-off。
  • AI：能解釋 inference / embeddings / RAG，並完成一個小型 AI solution。
  • 溝通：能用英文做 8–10 分鐘架構 demo，回答追問時不亂猜。
